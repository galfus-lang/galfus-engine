# galfus-browser

WebAssembly packaging for the complete Galfus Engine API in modern browsers.

The crate re-exports the generated WebAssembly binding shared with the native API. Its public
TypeScript entry point is the generated `sdk/browser/galfus.ts` facade, which provides platform,
Multiverse, resources, animation, and 2D/3D realm operations through one API surface.

## Usage

```typescript
import init, * as wasm from './pkg/galfus_browser.js';
import { initializeGalfusBrowser } from './sdk/browser/galfus.js';

const galfus = await initializeGalfusBrowser({ ...wasm, default: init });
galfus.platformInit();

const windowId = galfus.windowCreate({
  id: 1,
  title: 'Galfus WebGPU Demo',
  size: [1280, 720],
  canvasId: 'galfus-canvas',
  resizable: true
});

await galfus.multiverseAttachWindow(windowId);
```

The host owns the animation loop and should call `platformPumpEvents()`, update its state, and
dispatch rendering from `requestAnimationFrame`.

Browser audio is implemented by the SDK with Web Audio. Call `enableAudio()` from a user gesture
before playback, as required by browser autoplay policies.

## Scope

- WebAssembly output is generated by `wasm-bindgen` from the shared engine API.
- Canvas resizing is normalized by `galfus-platform`; the host forwards resize events to the
  Multiverse when its rendering target requires it.
- Desktop Node-API and C FFI bindings are provided by `galfus-native`.
