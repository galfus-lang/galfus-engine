# galfus-demo

Default executable runner for demos, integration prototypes, and functionality testing across the Galfus Engine workspace.

## Responsibilities

- **Demo Executable**: Provides a default binary (`cargo run`) to execute interactive graphical demos and prototypes.
- **Functionality Testing**: Serves as the integration testbed for native windowing, GPU pipelines, realm rendering, and graph execution.
- **Developer Sandbox**: Allows rapid validation of new features and cross-crate integrations without requiring external host bindings.

## Usage

Run directly from the root workspace:

```bash
cargo run
```
